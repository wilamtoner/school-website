
## Dependencies

- Bootstrap 5.3.0 (CDN)
- Bootstrap Icons (CDN)
- Font Awesome 6.4.0 (CDN)
- Google Fonts (Poppins & Roboto)

## Browser Support

- Chrome (latest)
- Firefox (latest)
- Safari (latest)
- Edge (latest)
- Mobile browsers

## Customization

### Change Colors
Edit the CSS variables in `style.css`:
```css
:root {
    --primary-color: #2c3e50;
    --secondary-color: #3498db;
    --accent-color: #e74c3c;
}
