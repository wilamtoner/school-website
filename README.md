# Bright Future Academy Website

A modern, responsive school website with university-style header design.

## Features

1. **Modern University-Style Header**
   - Three-tier header structure
   - Social media integration
   - Search functionality
   - Share buttons

2. **Responsive Design**
   - Mobile-friendly navigation
   - Adjustable layouts for all screen sizes
   - Touch-friendly elements

3. **Sections Included**
   - Hero section with slider
   - Quick info statistics
   - About section
   - Academic programs
   - Administration
   - Activities
   - Facilities
   - Contact form
   - Footer with newsletter

## Setup Instructions

1. **Download all files** to a folder:
   - `index.html`
   - `style.css`
   - `script.js`

2. **Open `index.html`** in any modern web browser.

3. **Customize the content**:
   - Replace placeholder images with your own
   - Update contact information
   - Modify color scheme in CSS variables
   - Add your logo
